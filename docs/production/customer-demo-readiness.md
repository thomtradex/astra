# Astra Customer Demo Readiness Checklist

## Objetivo

Garantir que cada demonstração Astra para uma empresa de construção acontece com qualidade profissional.

---

# Ambiente

## Aplicação

- [ ] Sistema disponível
- [ ] Login funcional
- [ ] Dashboard carregado
- [ ] Dados de demonstração preparados

---

# Conta de demonstração

- [ ] Organização criada
- [ ] Utilizador administrador criado
- [ ] Utilizador gestor criado
- [ ] Permissões verificadas

---

# Dados da empresa exemplo

## Empresa

- [ ] Nome da empresa configurado
- [ ] Projetos adicionados
- [ ] Equipamentos adicionados
- [ ] Equipas adicionadas

---

# Fluxo da demonstração

## Antes da reunião

- [ ] Testar login
- [ ] Confirmar todos os ecrãs
- [ ] Verificar velocidade
- [ ] Confirmar ausência de erros

---

# Durante a demonstração

Mostrar:

1. Dashboard geral
2. Projetos ativos
3. Equipamentos
4. Manutenção
5. Indicadores
6. Segurança
7. ROI

---

# Depois da demonstração

Recolher:

- necessidades da empresa;
- número de utilizadores;
- número de obras;
- quantidade de equipamentos;
- próximos passos.

---

# Objetivo final

Converter demonstração em piloto de 30 dias.
