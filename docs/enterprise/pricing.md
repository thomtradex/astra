# Astra Pricing

## Starter

Para pequenas empresas de construção.

Inclui:

- Gestão de projetos
- Equipas
- Organização operacional
- Assistente inteligente básico


## Professional

Para empresas com várias obras.

Inclui:

- Todos os recursos Starter
- Inteligência operacional
- Automações
- Dashboards
- Gestão avançada


## Enterprise

Para grupos de construção.

Inclui:

- Todos os recursos Professional
- Integrações personalizadas
- Suporte dedicado
- Configuração empresarial
- Segurança avançada


## Modelo Comercial

Preço baseado em:

- número de utilizadores
- número de projetos
- complexidade operacional
- integrações necessárias
