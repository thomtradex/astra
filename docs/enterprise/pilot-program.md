# Astra Construction Pilot Program

## Objetivo

Validar impacto real numa empresa de construção.

## Duração

30 dias.

## Fase 1 — Setup

Semana 1:

- configurar empresa
- criar utilizadores
- importar projetos

## Fase 2 — Utilização

Semanas 2-3:

- utilizar Astra em operações reais
- recolher feedback

## Fase 3 — Avaliação

Semana 4:

Medir:

- tempo poupado
- adoção
- melhorias

## Resultado

Decisão:

- expansão
- contrato anual
- melhorias
