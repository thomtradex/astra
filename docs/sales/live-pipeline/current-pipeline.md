# Revisão semanal

Todas as semanas analisar:

1. Quantos leads novos foram adicionados?
2. Quantos contactos foram enviados?
3. Quantas respostas recebemos?
4. Quantas reuniões foram marcadas?
5. Quantas demos foram feitas?
6. Quantos pilotos começaram?
7. O que aprendemos?
