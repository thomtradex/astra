# Astra Pilot Customer Onboarding Checklist

## Antes do início

- Confirmar empresa cliente
- Definir responsável interno
- Confirmar objetivos do piloto
- Definir duração do piloto
- Confirmar utilizadores iniciais

## Configuração Astra

- Criar organização
- Criar utilizadores
- Configurar permissões
- Validar autenticação
- Configurar dados iniciais

## Importação operacional

- Adicionar locais/obras
- Adicionar ativos
- Configurar equipas
- Configurar manutenção

## Durante o piloto

- Reunião semanal
- Recolher feedback
- Medir utilização
- Identificar melhorias

## Final do piloto

- Apresentar resultados
- Rever métricas
- Propor continuidade
- Converter para cliente pago
