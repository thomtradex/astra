# Métricas

Medir:

- empresas contactadas;
- respostas;
- reuniões;
- demos;
- pilotos;
- clientes.

---

# Aprendizagem semanal

Responder:

1. Qual mensagem teve mais resposta?
2. Qual problema apareceu mais?
3. Qual tipo de empresa mostrou mais interesse?
4. Que objeções apareceram?
5. O que deve mudar?

---

# Regra

Os primeiros 10 clientes não servem apenas para vender.

Servem para descobrir:

- mercado ideal;
- mensagem certa;
- preço certo;
- processo certo.
