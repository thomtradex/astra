# Astra Post Demo Follow-up Process

## Objetivo

Garantir que cada demo gera um próximo passo claro.

---

# Dia 0 — Após demo

Enviar:

- agradecimento;
- resumo dos problemas identificados;
- benefícios Astra relevantes;
- próximo passo combinado.

---

# Dia 1-2

Confirmar:

- dúvidas;
- envolvimento do decisor;
- interesse no piloto.

---

# Dia 5

Enviar:

- caso de utilização;
- ROI estimado;
- proposta de piloto.

---

# Dia 7

Reunião de decisão.

Objetivo:

- avançar para piloto;
- definir equipa;
- escolher primeira obra.

---

# Se cliente não responder

Sequência:

## Mensagem 1

Relembrar objetivo inicial.

## Mensagem 2

Enviar novo insight relacionado com construção.

## Mensagem 3

Perguntar se prioridade mudou.

---

# Regras

Nunca terminar uma demo sem:

- próxima reunião marcada;
- responsável identificado;
- problema confirmado.

---

# Métrica

Medir:

- demos realizadas;
- follow-ups enviados;
- pilotos iniciados;
- conversões.
