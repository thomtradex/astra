# Astra Commercial Closing Process

## Objetivo

Transformar oportunidades qualificadas em clientes pagantes.

---

# Após demo

Nunca terminar uma demo sem:

- problema confirmado;
- interesse validado;
- próximo passo marcado.

---

# Fase 1 — Avaliação

Confirmar:

- problema operacional existe;
- equipa sente impacto;
- existe responsável;
- existe orçamento possível.

---

# Fase 2 — Piloto

Definir:

- obra escolhida;
- duração;
- equipa envolvida;
- objetivo;
- métricas de sucesso.

---

# Fase 3 — Resultados

Medir:

- utilização;
- problemas resolvidos;
- tempo poupado;
- melhoria operacional.

---

# Fase 4 — Proposta comercial

Enviar:

- resumo do problema;
- solução Astra;
- resultados;
- preço;
- próximos passos.

---

# Fase 5 — Negociação

Registar:

- objeções;
- pedidos;
- alterações;
- decisão.

---

# Estados finais

A:
Cliente fechado.

B:
Negociação ativa.

C:
Follow-up futuro.

D:
Perdido com motivo registado.

---

# Regra

Nenhuma oportunidade pode existir sem:

- estado;
- próxima ação;
- responsável;
- data.

---

# Métrica final

Medir:

leads → reuniões → demos → pilotos → contratos.
