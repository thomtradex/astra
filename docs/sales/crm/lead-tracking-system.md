# Astra Construction Lead Tracking System

## Objetivo

Criar um sistema simples para acompanhar os primeiros 100 clientes potenciais de construção.

## Pipeline

### Lead identificado
Dados mínimos:
- Empresa
- Website
- País
- Número de colaboradores
- Tipo de construção
- Pessoa de contacto

### Contactado
Registar:
- Data primeiro contacto
- Canal utilizado
- Mensagem enviada
- Resposta

### Reunião marcada
Guardar:
- Data
- Participantes
- Problemas identificados
- Interesse

### Demo realizada
Avaliar:
- Interesse técnico
- Interesse comercial
- Necessidade de piloto

### Piloto proposto
Registar:
- Empresa
- Datas
- Objetivos
- Métricas de sucesso

### Cliente fechado
Guardar:
- Contrato
- Plano onboarding
- Responsável cliente

## Métricas semanais

- Novos leads adicionados
- Contactos enviados
- Respostas recebidas
- Demos marcadas
- Pilotos propostos
- Clientes ganhos

## Regra inicial

Primeiros 100 contactos devem gerar aprendizagem:
- quais empresas respondem
- quais problemas aparecem
- quais argumentos convertem
