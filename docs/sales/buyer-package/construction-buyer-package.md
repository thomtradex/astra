# Astra Construction Buyer Package

## Objetivo

Dar a um decisor de construção toda a informação necessária para avaliar a Astra.

---

# 1. O problema

Empresas de construção normalmente enfrentam:

- falta de visibilidade das obras;
- informação espalhada;
- dificuldade em acompanhar equipas;
- atrasos na tomada de decisão.

---

# 2. A solução Astra

A Astra ajuda empresas de construção a:

- centralizar informação operacional;
- acompanhar obras;
- melhorar controlo;
- tomar decisões com melhor informação.

---

# 3. Quem beneficia

Utilizadores:

- gestores de obra;
- diretores de operações;
- responsáveis de projeto;
- administração.

---

# 4. Processo de implementação

Primeiros 30 dias:

Semana 1:
- configuração;
- onboarding.

Semana 2:
- utilização inicial.

Semana 3:
- recolha de feedback.

Semana 4:
- análise de resultados.

---

# 5. Como medir sucesso

Avaliar:

- tempo poupado;
- informação encontrada mais rapidamente;
- melhoria do controlo operacional;
- utilização pela equipa.

---

# 6. Próximo passo

Após avaliação:

A:
Avançar para contrato.

B:
Ajustar piloto.

C:
Agendar nova revisão.

---

# Regra

Nunca enviar apenas uma demo.

Enviar sempre:

- contexto;
- problema;
- solução;
- próximo passo.
