# Astra Construction Commercial Proposal

## Proposta de implementação

Astra - Plataforma inteligente de gestão operacional para construção

---

# Resumo executivo

A Astra ajuda empresas de construção a melhorar controlo operacional, gestão de equipamentos e acompanhamento das suas operações.

Através de uma plataforma centralizada, as equipas conseguem reduzir informação dispersa e tomar decisões com maior rapidez.

---

# Objetivos

A implementação Astra pretende:

- centralizar informação operacional;
- melhorar visibilidade sobre recursos;
- reduzir processos manuais;
- aumentar controlo sobre equipamentos;
- criar uma base de decisão através de dados.

---

# Programa piloto

## Duração
