# Astra — Objeções Comerciais

## "Já usamos software de gestão"

Resposta:

A Astra não substitui necessariamente todas as ferramentas existentes.

Funciona como uma camada inteligente para ligar informação, processos e decisões.

---

## "Não temos tempo para implementar"

Resposta:

O processo começa com um piloto controlado.

A prioridade é provar valor rapidamente antes de uma expansão.

---

## "Qual é o retorno?"

Resposta:

Medimos:

- tempo administrativo poupado
- redução de erros
- melhoria de visibilidade
- velocidade de decisão

---

## "Precisamos de segurança"

Resposta:

A Astra foi desenhada com:

- permissões
- controlo de acesso
- logs
- processos de validação
