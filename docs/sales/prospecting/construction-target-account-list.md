# Astra Construction Target Account List

## Objetivo

Criar uma lista inicial de empresas de construção para abordagem comercial.

---

# Critérios de seleção

Prioridade para empresas com:

- várias obras simultâneas;
- equipas de terreno;
- necessidade de controlo operacional;
- crescimento recente;
- problemas de comunicação entre escritório e obra.
