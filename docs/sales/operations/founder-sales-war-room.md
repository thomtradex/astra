# Astra Founder Sales War Room

## Objetivo

Criar disciplina diária para conquistar os primeiros clientes de construção.

---

# Ritual diário

Todos os dias:

## Manhã

Rever:

- novos leads;
- follow-ups pendentes;
- reuniões marcadas;
- prioridades.

---

## Execução

Objetivo diário:

- novos contactos enviados;
- respostas analisadas;
- chamadas marcadas;
- oportunidades avançadas.

---

# Métricas principais

Medir:

- contactos enviados;
- respostas;
- reuniões;
- demos;
- pilotos;
- contratos.

---

# Estado das oportunidades

Cada oportunidade deve ter:

- empresa;
- contacto;
- problema;
- fase;
- próximo passo;
- data.

---

# Revisão semanal

Responder:

1. Quantas empresas foram contactadas?
2. Quantas responderam?
3. Qual mensagem funcionou melhor?
4. Que problemas apareceram?
5. Que melhorias devem ser feitas?

---

# Regra

Nenhuma oportunidade fica parada.

Toda oportunidade precisa de:

- próxima ação;
- responsável;
- prazo.
