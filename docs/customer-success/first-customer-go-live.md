# Astra First Customer Go-Live Checklist

## Objetivo

Garantir uma implementação profissional quando a primeira empresa de construção começa a utilizar a Astra.

---

# Antes do início

## Cliente

- [ ] Contrato piloto aprovado
- [ ] Responsável do cliente definido
- [ ] Objetivos do piloto definidos
- [ ] Equipa inicial identificada

---

# Configuração Astra

- [ ] Organização criada
- [ ] Utilizadores adicionados
- [ ] Permissões configuradas
- [ ] Dados iniciais carregados

---

# Dados iniciais

Adicionar:

- [ ] Obras
- [ ] Equipamentos
- [ ] Equipas
- [ ] Recursos
- [ ] Informação operacional relevante

---

# Formação

Realizar:

- [ ] Sessão administrador
- [ ] Sessão gestores
- [ ] Sessão utilizadores finais

---

# Primeira semana

Monitorizar:

- utilização;
- dúvidas;
- erros;
- feedback;
- necessidades adicionais.

---

# Revisão intermédia

Após 15 dias:

- avaliar adoção;
- medir resultados;
- ajustar configuração.

---

# Final do piloto

Após 30 dias:

Rever:

- valor criado;
- utilização;
- melhorias;
- próximos passos.

---

# Objetivo final

Converter piloto em cliente Astra permanente.
