# Astra Demo Scenario

## Situação inicial

A empresa tem várias obras simultâneas.

Os gestores precisam de:

- acompanhar progresso
- comunicar com equipas
- controlar documentação
- analisar problemas


## Demonstração Astra

Mostrar:

1. Organização da empresa

2. Projetos ativos

3. Equipas responsáveis

4. Informação centralizada

5. Inteligência operacional


## Resultado esperado

Após utilização:

- decisões mais rápidas
- menos tarefas repetitivas
- melhor controlo das operações
