# Astra Site Manager Flow

## Objetivo
Mostrar como um gestor de obra utiliza a Astra diariamente.

## Fluxo

1. Login da empresa
2. Seleção do projeto
3. Dashboard da obra
4. Estado dos recursos
5. Alertas de manutenção
6. Histórico de atividades
7. Relatórios

## Resultado comercial

A empresa consegue reduzir falhas operacionais,
melhorar controlo da obra e centralizar informação.
